we-mpkg 2.4.9-beta.4
====================

测试版，只发布安卓 APK。本轮修 UI 五项。

1. 状态栏真正沉浸
   - 上一版只是把状态栏刷成深色，内容仍被挤到状态栏下方，所以看着是「深色横条 + 断层」
   - 改为不再给原生 View 加 padding，把状态栏/导航栏高度按 dp 以 CSS 变量 --sat/--sab 下发到网页，页面自己排布
   - 内容现在能一直铺到屏幕顶部（列表滚动时从透明状态栏下方流过），顶栏自己按 --sat 让出安全区
   - 每次页面导航后（onPageFinished）重新注入一次变量，避免刷新后丢失

2. 首页顶部空白过大
   - 空白就是上一版 content 根容器的 insets padding + 顶栏自身 padding 叠加出来的
   - 去掉原生 padding 后，顶部只保留顶栏自身的 --sat 安全区，不再有多余空档

3. 回到顶部悬浮按钮
   - 右下角圆形按钮，滚过 400px 才出现，点击平滑回顶；位置按 --sab 避开手势条

4. 设置齿轮居中
   - .ghost / .icon 改成 inline-flex 居中，解决 ⚙ 字形基线偏下、视觉不在按钮中心的问题

5. 搜索框聚焦弹出
   - 手机端点搜索框：整行变成 fixed 停在屏幕顶部（含安全区），带 0.22s 上弹 + 轻微缩放的拉伸动画
   - 聚焦时先回顶部，输入中不会被「滚动收放」逻辑收走；失焦 120ms 后恢复原状
   - 桌面宽度（>640px）保持原样，不做弹出

其他：compileSdk/targetSdk 维持 36；全量测试 121 通过 / 0 失败 / 1 跳过；assets 已重打（buildId 2ace95cf…）
