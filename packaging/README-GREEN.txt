we-mpkg 绿色版 —— 浏览 Wallpaper Engine 创意工坊 → 下载 → 打包成手机版 .mpkg

一、怎么启动
------------------------------------------------------------
双击 start.bat
  · 会开一个黑色窗口跑本地服务，并自动打开浏览器 http://localhost:3090
  · 窗口别关，关掉就等于停止服务
  · 端口被占用时可以指定，例如：start.bat 3095

怎么退出
  · 网页右上角 ⚙ → 设置 → 最下面「退出程序（关闭后台服务）」，点一下后台就停了
  · 或者双击 stop.bat（默认 3090，可传端口：stop.bat 3095）
  · 直接关掉黑色窗口也可以
  · 只关浏览器不会停服务，后台仍在跑，下次再打开 http://localhost:3090 就能直接用

只想用命令行：
  run.bat help                查看全部命令
  run.bat search 白毛         搜索
  run.bat pack <目录或.pkg>    把本地目录打包成 mpkg
  run.bat steamjs status      查看当前登录状态

二、第一次要做的两件事
------------------------------------------------------------
1) 登录（必须有拥有 Wallpaper Engine 的账号，匿名下载是拿不到密钥的）
   方式 A（推荐，只有一台电脑/一部手机都行）：
       双击 get-token.bat → 会打印一整段 Base64
       在网页右上角 ⚙ → 设置 → 填账号和密码 → 登录
       （密码只用于这一次登录，不落盘；装了 Steam App 的手机会收到「确认登录」，点一下就行）
   方式 B：把 get-token.bat 打印的那段 Base64 粘到安卓 App 启动页的「登录凭据」→ 导入凭据

2) 选下载目录（可选）
   网页右上角 ⚙ → 设置 → 下载目录，填一个绝对路径即可（默认是 output 子目录）

三、日常使用
------------------------------------------------------------
搜索 / 排序 / 筛选（按创意工坊原版分组：类型、年龄分级、分辨率、题材……）
点卡片 → 下载并打包 → 完成后直接在网页上「保存 .mpkg」
把 .mpkg 拷到手机，用手机的壁纸引擎导入即可。

四、目录说明
------------------------------------------------------------
start.bat          启动网页界面（主入口）
stop.bat           关闭后台服务（网页里点「退出程序」等价）
run.bat            命令行入口（所有子命令）
get-token.bat      取手机端要用的登录凭据
nodejs\node.exe    自带 Node 运行时（不用另外装 Node）
bin\ src\ public\  程序本体
node_modules\      依赖
.cache\            登录凭据、设置（第一次运行后自动生成）
downloads\         临时下载文件
output\            产出的 .mpkg
logs\              日志

五、常见问题
------------------------------------------------------------
Q: 网页上按钮写着「先登录再下载」？
A: 那是没登录，不是平台不支持。点右上角 ⚙ 填账号密码登录（或导入 get-token.bat 的凭据）即可。

Q: 下载 video 之外的壁纸（scene / pkg 类）行不行？
A: 可以。scene 类会下载 scene.pkg 并解包进 mpkg。想要原始文件不打包，就在设置里勾
   「只下载原始文件（不打包 mpkg）」，文件会原样落在 downloads\js-<条目ID>\ 里。

Q: 还用 SteamCMD 吗？
A: 不了。2.1 起只剩内置的纯 JS 下载引擎，不用安装 SteamCMD，也不用管 SteamCMD 的登录态。

Q: 下载很慢或连不上 Steam？
A: 绿色版会自动读取 Windows 系统代理；也可以设环境变量再启动：
   set WE_MPKG_PROXY=http://127.0.0.1:7890 && start.bat

Q: 打包 scene 类壁纸时提示缺少纹理？
A: 旧版才有这个问题。现在直通编码图纹理会自动物化成 RGBA8、着色器也会自动做 GLSL ES 兼容改写，
   不需要参考 mpkg 了；refs\<条目ID>.mpkg 只在你想用官方包做对照时才有用。

Q: 网页（web）类型的壁纸打出来在手机上黑屏？
A: 手机版壁纸引擎**根本没有 Web 引擎**（只有一个 Scene/Video 渲染库），网页类必然黑屏，这不是打包问题。
   本工具的做法是：用电脑上的 Edge/Chrome 无头渲染这个网页，编成 mp4，再按 video 类型封装 —— 手机端就能正常播放。
   代价是丢失交互、多屏和音频反应，只保留动画。
   · 需要本机有 Edge 或 Chrome（Windows 一般自带 Edge）+ ffmpeg。
   · ffmpeg 放这里即可被自动找到：.cache\toolchain\ffmpeg\bin\ffmpeg.exe
     （也可以设环境变量 WEM_FFMPEG=<ffmpeg.exe 的完整路径>）
   · 缺 ffmpeg 时会明确警告并退回原样封装（手机上仍会黑屏），不会假装成功。
   · 参数：run.bat pack <目录> --web-seconds 8 --web-fps 24 --web-layout letterbox|full|auto
   · 手机 App 里打包没有浏览器也没有 ffmpeg，所以 web 类只能在电脑上打包。

Q: 4K / 竖屏视频纹理的壁纸，打包后手机黑屏或卡顿？
A: 视频纹理超过 1920（按最长边算）会自动转码：H.264 Constrained Baseline + yuv420p，
   竖屏锁高度、横屏锁宽度，再把纹理头尺寸改成与视频流一致。
   · 绿色版已内置精简版 ffmpeg：tools\ffmpeg\ffmpeg.exe，开箱即用（约 60 MB）。
   · 想换自己的：设环境变量 WEM_FFMPEG=<ffmpeg.exe 完整路径>，优先于内置。
   · 找不到 ffmpeg 时不会假装成功：打包结果里会给警告，说明这条纹理保持原样、
     手机端可能读不出画面。
   · 安卓 App 内没有内置 ffmpeg，4K 视频纹理只能原样保留；需要转码的话请在电脑上打包。

六、转移 / 卸载
------------------------------------------------------------
整个文件夹拷走就能在另一台 Windows 上直接跑（真正的绿色版，不写注册表、不装服务）。
不想要了直接删文件夹即可。

合规提醒：仅用于下载你有权访问的内容（需自备拥有 Wallpaper Engine 的账号）。
