we-mpkg 2.4.12
==============

正式版。三件事：关于页能看到当前版本、启动时自动检查更新；缓存回收的保留份数跟上 3 并发；清掉一处历史遗留的 BOM。

## 版本可见 + 自动检查更新
- 设置 → 关于页顶部直接显示「当前版本 v2.4.12」，来源是 package.json，不再靠翻 Release 页对版本。
- 启动时自动查一次 GitHub 最新 Release（走服务端 6 小时缓存，不额外打请求）；有新版本会在顶栏下方弹一条提示，
  点「去更新」：安卓端直接下 APK，桌面端打开 Release 页。
- 同一条更新提示关掉后（右上角 ×）不再重复弹，换版本才会重新提示；断网或接口失败时静默，不打扰。
- 手动「检查更新」按钮改成复用同一套渲染逻辑，关于页的状态和顶栏提示条始终一致。

## cachegc 与 3 并发
- 临时目录（pkg-<ts> / pack- / webrender）的保留份数从 2 提到 4：
  下载中心最多同时跑 3 条任务，每条都会留下自己的临时目录，留 2 份会把还在跑的那条当成残骸回收。

## 清理
- src/ffmpeg.js 开头那处多余 UTF-8 BOM 去掉了。只有 .ps1 需要 BOM（Windows PowerShell 5.1 解析中文注释要用），
  JS 一律不带；顺手加了测试守卫，src / tools / public 下的 JS 再出现 BOM 会直接失败。
