we-mpkg 2.4.16
==============

依赖清理正式版：安装包与运行依赖更瘦，已知高危减少一半，功能行为不变。

## 变更
- 给 steam-appticket 加 npm overrides，强制它使用 protobufjs ^7.6.6，不再安装嵌套的 6.11.6。
  node_modules 从 53 MB 降到 30 MB（省约 22 MB，其中 19.5 MB 是 6.x 自带、手机端用不到的命令行工具）。
- npm audit 高危从 4 条降到 2 条（剩下 2 条来自 steam-user 依赖的 adm-zip，需单独验证，本版不动）。
- 新增守卫测试：锁文件里不允许再出现 protobufjs 6.x。

## 验证
- 2.4.16-beta.1 已在真机验证：同一签名覆盖安装正常，登录 Steam 后下载工坊条目正常（app ticket 解析路径无异常）。
- 本地与 CI 全量测试 140 通过 / 0 失败 / 1 跳过。

## 签名与升级
本版与之前各版使用同一 release 签名，versionCode 59（beta 为 58），可直接覆盖 beta 或 2.4.15。
