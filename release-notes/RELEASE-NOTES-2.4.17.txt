we-mpkg 2.4.17
==============

修两个同源的老问题：壁纸的「元素选项」在手机端切换没反应；双主题壁纸的第二套主题导入后永远调不出来。

## 修复
- 打包时不再把所有对象形式的 visible 一键固化成布尔。旧逻辑会把 {user:"snake", value:true} 这类
  属性绑定写成 true/false，墙面看着和作者预设一致，但属性链接被抹掉，导入后选项拨了画面不动。
- 由「用户属性」控制、且该属性确实写在 project.json 里的图层现在原样保留，交给壁纸引擎运行时切换；
  双主题壁纸的另一套主题就靠它调出来。
- 属性读不到的、没有 user 的纯值对象仍然按当前值固化，避免手机端把对象当成 true 导致两套图层叠在一起。
- 想回到旧行为（全部固化）：设置环境变量 WEM_PRESERVE_VISIBLE=0 后重新打包。

## 注意
- 已经打包好的旧 mpkg 不会自动变好，需要用本版重新打包一次。
- 移动端能否真的切出主题 2 取决于 WE 手机端对 visible 对象的支持；如果两套主题叠在一起，
  把 WEM_PRESERVE_VISIBLE 设成 0 重打即可回退。

## 验证
- 本地全量测试 141 通过 / 0 失败 / 1 跳过（新增双主题可见性用例）。
- 用 BanG Dream! 薇欧拉（3842878979）实打：5 处 visible 保持 {"user":"snake"/"time"/"audio"} 对象形式，
  手机端「蛇 snake / 时间 Time / 音频响应 Audio」三个选项切换恢复正常。
- android/assets 的 nodejs-project.zip 已重打，APK 内 JS 与仓库源码一致。

## 签名与升级
本版沿用同一 release 签名，versionCode 60（上一版 59），可直接覆盖 2.4.16 安装。
