we-mpkg 2.4.20

【下载进度条重做】

1. 速率显示修正
   以前每次进度回调都会刷新速度采样的时间基准，采样窗口永远凑不满，于是
   「x.x MB/s」长期不动、或者突然跳到奇怪的值。现在固定用 ≥600ms 的窗口
   算一次速率再平滑，换文件 / 重试导致字节回退时旧速率直接作废。
   剩余时间（ETA）也按同一个速率算，不再出现忽长忽短。

2. 下载与打包分成两层进度
   一个任务其实是「下载 → 纹理转换 / 着色器适配 / 写入 mpkg」两件事，以前
   共用一条进度条：下载走到 99% 后打包又把百分比从头算，看起来像下载失败重来。
   现在：
   - 底层浅色条 = 下载进度，下载完就锁在 100%，打包阶段变淡表示「已下完」；
   - 上层深色条 = 打包进度，从左侧覆盖上去，一直走到 100%；
   - 文字同步改成「下载 100% · 打包 43% · 12/28 张」，打包阶段不再挂一个 0 B/s 的速率。
   详情页、下载中心浮层、独立下载中心页、顶栏任务条四处一致。

3. 顺手改的
   - 打包子阶段按权重折算成 0-100（解包检查 / 纹理转换 / 着色器 / 替换资源 / 写入 mpkg），
     没有细分计数的阶段按时间缓慢爬升，不会长时间钉在一个数字上。
   - 纹理张数（done/total）单独记录，不再和下载字节共用字段。
   - 新增两条测试覆盖速率采样与分层进度（142 通过 / 0 失败 / 1 跳过）。
