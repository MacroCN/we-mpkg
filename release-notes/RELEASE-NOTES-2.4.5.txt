we-mpkg 2.4.5

修复
- 场景壁纸导出后图层上下颠倒：桌面端 .tex 的像素按「行 0 在底部」存储，手机端引擎按「行 0 在顶部」上传。转换时对解码路径（DXT / RGBA8 / R8 / RG88）统一翻正一次，已是移动端形态的纹理（单 mip RGBA8/ETC2）保持原样、不再被二次翻转。
- 「导出原始资源」在已经是解包形态的场景工程（有 scene.json、没有 scene.pkg，例如 .mpkg）上会误报「场景壁纸缺少 scene.json，无法导出原始资源」，现在改为原样打包工程目录。

测试
- 新增用例：桌面端 RGBA 转换后首行应翻到顶部；移动端形态必须原样保留（120 通过 / 0 失败 / 1 跳过）。
