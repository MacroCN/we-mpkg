we-mpkg 2.4.7

修复
- 「导出原始资源」误报失败：部分条目的 project.json 里 file 写的是 scene.json，但目录里实际载荷是 scene.pkg，原来按 file 直接找路径会报「场景壁纸缺少 scene.json，无法导出原始资源」。现在 file 不是 .pkg 且目录里存在 scene.pkg 时，按 scene.pkg 解包导出。

说明
- 2.4.5/2.4.6 的纹理行序翻转实验已全部撤销，纹理转换回到 2.4.4 的行为。经与官方客户端确认，个别场景壁纸在手机端整体上下翻转属于壁纸引擎移动端自身的兼容问题（官方转换结果一致），we-mpkg 不做启发式翻转，以免影响其他壁纸。

测试
- 新增用例：file=scene.json 但有 scene.pkg 时必须能导出 raw zip（121 通过 / 0 失败 / 1 跳过）。
