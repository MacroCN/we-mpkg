we-mpkg 2.4.9
=============

正式版。安卓 targetSdk 升到 36（Android 16），移动端交互按真机反馈重做了一轮。

## 安卓
- targetSdk 34 → 36，compileSdk 同步 36（AGP 8.13.2 / Gradle 8.14.8 不变），minSdk 24
- 返回键改用 OnBackInvokedCallback：修复 target 36 预测性返回下「页面内返回直接退出应用」
  优先级仍是：下载浮层 → 网页弹窗/详情抽屉 → 网页历史 → 启动页 → 退到后台
- 沉浸式状态栏：不再用原生 padding 顶内容，安全区改以 CSS 变量 --sat/--sab 下发；
  列表可以从透明状态栏下方流过，启动页单独避让状态栏
- 详情页：加半透明遮罩，点任意位置关闭（关闭键不再必须够得到）
- 搜索框聚焦：只放大输入框本身（占满整行、加高），不再是整行弹出
- 筛选栏：所有宽度下都是限高 46vh 的可滚动容器，修掉「展开后滚不动」
- 首页：下拉刷新（下拉 → 松开刷新 → 刷新中）、回到顶部悬浮按钮
- 顶栏/搜索栏随滚动收放：上滑隐藏、下滑出现，输入时不会被收走
- 设置-关于：补项目地址、Issues、项目简介
- 设置齿轮居中；详情抽屉/日志不再被下拉刷新抢走手势

## 筛选中文
- 启动时并行抓官方英文页与中文页，按稳定的 tag id 生成「英文 → 官方中文名」对照表
  （分组配对也改按 tag id 交集，不再依赖顺序，避免后置分组整体错位）
- 官方页不翻译的 WE 自有术语走内置词表：素材类型（粒子/图像/声音/模型/文字/序列帧/全屏/合成/脚本/特效/脚本图层）、
  素材题材（音频可视化/背景/角色/时钟/火焰/交互/魔法/后处理/烟雾/太空 等）、脚本类型（无动画/超大尺寸；
  Boolean、Number、Vec2~Vec4、String 属数据类型，保持英文）
- 只影响显示：请求仍传 Steam 原始英文 tag 名，筛选语义与官方一致

## 构建
- beta 阶段修了一轮 CI：依赖 job 被跳过时仍能发布、concurrency 串行、checkout 浅克隆、
  Android SDK / 预编译原生库 / ffmpeg 缓存
- 16 KB 页对齐保持（四个 .so 的 LOAD 段 p_align 均为 16384）
