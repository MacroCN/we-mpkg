we-mpkg-rs 3.0.3（versionCode 92）

修复（按审核结论逐条跟进）
- DXT3/DXT2 alpha 改为标准 S3TC 排布：16 个 4bit alpha 连续占满 8 字节，像素 (x,y) 取 nibble 4y+x。
  旧实现按「每行 1 字节」读，只有第 0 行正确，第 1–3 行 alpha 全部错位——这是 2.0 起就存在的移植缺陷；
  2.5 以来的 2.x 正式包同样受影响，带透明渐变的 DXT3 纹理边缘会出现错位。
- 整包纹理批处理改为每 32 张一批；批失败（超时/崩溃）自动逐张重跑，不再一次性把整包纹理标失败导致手机端黑屏。
- PNG 补 Adam7 隔行支持（原来的 pngjs 有，搬 Rust 时漏了）：隔行 PNG 不再被判失败而保留 PC 纹理。
- Rust 手写解码器（PNG/JPEG/inflate）补齐段边界与表编号校验：DQT/DHT/SOS 越界、表号 >3、
  频谱范围 >63、扫描块越界都改为正常报错。对 2100 个变异样本模糊测试，0 panic（此前 JPEG 会有 abort）。
- rusttex 临时目录前缀改为 pkg-rusttex-*，纳入 cachegc 清理，进程被强杀不再留残骸。
- dxtDecode 返回 null（临时目录不可用）时给出明确错误，不再 TypeError。
- lz4 注释与实现统一：引擎存在但执行失败直接抛错，引擎不存在才走 JS。

测试
- 新增 DXT3 alpha 布局回归、Adam7 隔行 PNG 黄金样本、解码器模糊自检。
- 全量 156 通过 / 0 失败 / 1 跳过。

已知遗留
- 应用内更新检查已在 3.0.2 指向新仓库；本版沿用。
